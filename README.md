# GTLab — лаборатория теории игр

Сайт, на котором боты-стратегии сражаются в играх теории игр в реальном времени.
Можно выбрать ботов и столкнуть их в турнире, посмотреть любой матч раунд за раундом,
собрать турнир команд по нескольким играм с табло как на соревнованиях, написать свою
стратегию на JavaScript и пройти короткий курс с экспериментами.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Уроки** | 12 уроков (Нэш, Аксельрод, шум, обратная индукция, эволюция, эскалация, системы) + мини-игра «Угадай бота» |
| **Эфир** | Сервер круглосуточно проводит турниры команд; все зрители видят их в реальном времени (SSE) |
| **Турниры** | Командный турнир по нескольким играм: место в каждой игре, сумма мест, пьедестал, «сюжеты», табло на весь экран |
| **Арена** | Одна игра, выбранные боты, «каждый с каждым», перекрёстная таблица, репликаторная динамика |
| **Игры** | 8 игр: дилемма заключённого, охота на оленя, ястреб и голубь, дилемма путешественника, общественное благо, перетягивание каната, ультиматум, аукцион двойной цены |
| **Песочница** | Своя стратегия `play(ctx)` на JS, проверка против всех ботов, сохранение в браузере |

Все матчи считаются в Web Worker в браузере, сервер нужен только для эфира.
Зависшая пользовательская стратегия останавливается через 5 секунд.

## Запуск

```bash
npm start          # http://localhost:3000
npm test           # проверка движка
```

Зависимостей нет — только Node.js 18+.

## Деплой на Render

`render.yaml` — Blueprint: бесплатный web service, `npm start`, health check `/api/health`.

**Антислип.** Бесплатный инстанс Render засыпает после 15 минут без входящих запросов.
Сервер каждые `KEEPALIVE_INTERVAL_MIN` минут (по умолчанию 10) обращается к своему
публичному адресу `RENDER_EXTERNAL_URL` — Render задаёт эту переменную сам, запрос
проходит через внешний балансировщик и считается входящим. Состояние видно в `/api/health`.
Запасной вариант — внешний пингер (например, cron-job.org) на `/api/health`.

**Не индексируется.** Каждый ответ отдаёт `X-Robots-Tag: noindex, nofollow, noarchive`,
в HTML стоят `meta robots/googlebot/yandex`. `robots.txt` обход не запрещает специально:
иначе поисковик не увидит `noindex` и может показать голый адрес в выдаче.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | 3000 | порт (Render задаёт сам) |
| `KEEPALIVE_INTERVAL_MIN` | 10 | период самопинга |
| `KEEPALIVE_URL` | `RENDER_EXTERNAL_URL` | адрес для самопинга |
| `KEEPALIVE_DISABLED` | — | `1` — выключить антислип |
| `LIVE_MATCH_DELAY_MS` | 700 | пауза между матчами в эфире |
| `LIVE_PAUSE_MS` | 45000 | пауза между турнирами эфира |
